# MAP Career Assist

MAP 的私人 Chrome 扩展。它可以保存当前 LinkedIn 岗位，也可以使用只存在这台电脑上的申请资料填写招聘网站的空白字段。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本仓库中的 `extension` 文件夹。
5. 在 Chrome 工具栏的拼图菜单里，把 `MAP Career Assist` 固定到工具栏。

更新代码后，请回到 `chrome://extensions`，在 `MAP Career Assist` 卡片上点击一次重新加载按钮。

## 使用

1. 在桌面版 Chrome 打开一个 LinkedIn 岗位详情页，必要时先展开完整岗位描述。
2. 点击工具栏中的 MAP 图标。
3. 在右侧面板检查自动提取的字段。之后在 LinkedIn 切换其他岗位时，面板会跟随 URL 自动更新，不需要反复点击读取。
4. 已经确认信息时点击「直接保存」，MAP 会在后台自动校验、去重并写入看板，不会把你从 LinkedIn 切走。
5. 想先修改内容时点击「先预览」，在 MAP 编辑窗口里再次确认。

“直接保存”复用 MAP 已登录的安全会话，不在扩展中保存长期数据库密钥。如果 MAP 登录已经失效，需要先打开 MAP 登录一次。

如果 MAP 尚未登录，会先出现登录页面。登录完成后重新点击一次扩展即可。Chrome 手机端不支持扩展。

## 自动填写申请表

1. 在扩展中切换到「自动填表」，点击「编辑我的申请资料」。
2. 只填写愿意自动使用的信息；把多段工作经历按“最近一段在最前”的顺序添加并保存。资料位于 `chrome.storage.local`，不会发送到 MAP 或 AI。
3. 回到招聘申请页面，点击「填写当前页面」。第一次使用某个网站时，Chrome 会询问是否允许访问该网站。
4. 多步骤申请可以开启「在这个网站持续填写」。新表单出现后会自动填写；关闭开关会同时停止并移除该网站的可选权限。

扩展会把公司、职位、地点、起止年月、当前任职状态和职责描述作为一整段经历填写；申请表需要更多经历时，只会点击明确标注为“Add work experience”的按钮继续展开。自动填写只写入空白字段，不覆盖已有内容、不上传文件、不点击提交，也不会处理密码、SIN/SSN、出生日期、人口统计、薪资、签名或银行卡信息。基础匹配不调用 AI，因此没有 API 用量。

Workday 招聘页面已包含在扩展的固定站点权限中。若表单把国家区号和电话号码拆成两个字段，请在资料页填写 `Country calling code`；扩展会把区号放进国家区号字段，并只把本地号码填进 `Phone Number`。
